# UC Tor

برنامه‌ی اندروید ساده و تک‌صفحه‌ای برای اتصال به شبکه‌ی Tor، مخصوص کاربران ایران.

- موتور: Tor رسمی (کتابخانه‌ی `tor-android` از Guardian Project) و IPtProxy برای پل‌ها
- روش‌های اتصال: خودکار، webtunnel، snowflake، obfs4، meek_lite، conjure (اگر در IPtProxy موجود باشد)، obfs3، scramblesuit، vanilla و اتصال مستقیم
- بریج‌ها: هر ساعت از Moat رسمی Tor، ۵ ریپوی گیت‌هاب و ۳ کانال تلگرام جمع‌آوری، تکراری‌ها حذف و تست می‌شوند
- **به‌روزرسانی مستقل از ریپو:** دکمه‌ی بروزرسانی ابتدا فایل `bridges.json` ریپوی شما را می‌گیرد. اگر این فایل قدیمی‌تر از ۲۴ ساعت بود یا ریپو در دسترس نبود، برنامه خودش مستقیم از Moat رسمی، ریپوهای گیت‌هاب و کانال‌های تلگرام بریج جمع می‌کند (ترجیحاً از راه Tor). در این حالت تست دسترسی TCP انجام نمی‌شود و بریج‌ها بر اساس تعداد منابعی که تأییدشان می‌کنند رتبه می‌گیرند. بریج‌های داخل APK فقط برای روشی استفاده می‌شوند که در لیست تازه هیچ بریجی ندارد.
- **VPN سراسری دستگاه** با Android VpnService + TUN + hev-socks5-tunnel: ترافیک TCP کل گوشی و DNS به Tor فرستاده می‌شود (Tor از UDP عمومی پشتیبانی نمی‌کند)؛ خود UC Tor از تونل مستثناست تا حلقه ایجاد نشود
- پروکسی محلی SOCKS5 و HTTP، با دکمه‌ی «افزودن به تلگرام»
- کانال تلگرام: [@UCIRANIR](https://t.me/UCIRANIR)

## راه‌اندازی (فقط یک بار)

1. یک ریپوی **Public** در گیت‌هاب بسازید. ریپو باید عمومی باشد تا برنامه بتواند بریج‌های تازه را دانلود کند.
2. **Settings ← Actions ← General ← Workflow permissions** را روی **Read and write permissions** بگذارید و ذخیره کنید.
3. **Settings ← Secrets and variables ← Actions ← New repository secret**:
   - Name: `SIGNING_PASSWORD`
   - Value: یک رمز طولانی و دلخواه. **این رمز را جایی امن نگه دارید**، چون بدون آن نسخه‌های بعدی روی نسخه‌ی قبلی نصب نمی‌شوند.
4. **Add file ← Create new file** را بزنید، اسم فایل را `.github/workflows/uctor.yml` بگذارید، محتوای همین فایل را داخلش کپی کنید و Commit کنید.
   (گیت‌هاب اجازه نمی‌دهد خود اکشن، فایل اکشن را بسازد. برای همین این مرحله باید دستی انجام شود.)
5. **Add file ← Upload files** را بزنید، فایل `UC-Tor.zip` را آپلود کنید و Commit کنید.

از این به بعد همه‌چیز خودکار است: اکشن زیپ را باز می‌کند، فایل‌ها را جایگزین می‌کند، کلید امضا را (فقط بار اول) می‌سازد، APK‌ها را می‌سازد و در بخش **Releases** منتشر می‌کند.

برای اینکه بریج‌ها همین حالا جمع‌آوری شوند: **Actions ← UC Tor ← Run workflow ← both**.

## نسخه‌های بعدی

فقط زیپ جدید را آپلود کنید. نسخه‌ی جدید با **همان کلید** امضا می‌شود، شماره‌ی نسخه‌اش خودکار بالا می‌رود و روی نسخه‌ی قبلی نصب می‌شود.

- شاخه‌ی `signing-keys` (کلید امضا) را **هرگز حذف نکنید** و اسم فایل اکشن را عوض نکنید.
- اگر بخواهید فایل اکشن هم از داخل زیپ به‌روز شود، یک Personal Access Token با دسترسی `Contents` و `Workflows` بسازید و با نام `WORKFLOW_TOKEN` در Secrets بگذارید.

## کدام APK؟

| فایل | برای |
|---|---|
| `arm64-v8a_new-phones` | بیشتر گوشی‌های جدید |
| `armeabi-v7a_old-phones` | گوشی‌های قدیمی ۳۲ بیتی |
| `universal_all-phones` | همه‌ی گوشی‌ها (حجم بیشتر) |

حداقل نسخه‌ی اندروید این نسخه‌ی VPN کامل: Android 10 (API 29)، چون کتابخانه‌ی TUN رسمی همین حداقل را اعلام می‌کند. دو ABI ساخته می‌شود: arm64-v8a برای گوشی‌های جدید و armeabi-v7a برای گوشی‌های قدیمی‌ترِ ۳۲بیتی. برای کامپایل، Android API 36 استفاده می‌شود.

## انتخاب کشور خروجی و فایل GeoIP

برای اینکه Tor عبارت `ExitNodes {de}` را بفهمد باید فایل‌های `geoip` و `geoip6` رسمی Tor را داشته باشد. تسک `downloadGeoip` در `app/build.gradle.kts` هنگام بیلد آن‌ها را از مخزن رسمی Tor داخل `app/src/main/assets/geoip` می‌گذارد (چند آدرس جایگزین دارد) و برنامه موقع اتصال آن‌ها را به حافظه‌ی داخلی کپی می‌کند و در torrc با `GeoIPFile` و `GeoIPv6File` معرفی می‌کند. هیچ نیازی به اینترنت روی گوشی ندارد.

- اگر دانلود هنگام بیلد ناموفق باشد، بیلد خراب نمی‌شود ولی در لاگ اکشن هشدار `[UC-GEOIP]` می‌آید و انتخاب کشور در همان نسخه کار نمی‌کند (حالت «خودکار» عادی است).
- می‌توانید دو فایل را دستی هم در `app/src/main/assets/geoip/` بگذارید؛ در این صورت دانلود انجام نمی‌شود.

## استفاده با تلگرام

بعد از اتصال، دکمه‌ی «افزودن به تلگرام» را بزنید. تلگرام پروکسی SOCKS5 روی `127.0.0.1` را اضافه می‌کند.

## نکته‌های امنیتی

- بریج‌های کامیونیتی (گیت‌هاب و تلگرام) را Tor Project تأیید نکرده است. این بریج‌ها نمی‌توانند رمزنگاری Tor را بشکنند، ولی IP شما را می‌بینند.
- تست بریج‌ها (وقتی فایل ریپو سالم است) از سرورهای گیت‌هاب انجام می‌شود، نه از داخل ایران. اگر برنامه خودش جمع‌آوری کند، اصلاً تست TCP ندارد. در هر دو حالت برنامه روش‌ها را یکی‌یکی روی اینترنت شما امتحان می‌کند.
- این برنامه جای Tor Browser را برای ناشناس ماندن کامل نمی‌گیرد.
