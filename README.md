## ✨ معرفی

**UC Tor** یک برنامه‌ی اندرویدِ تک‌صفحه‌ای و ساده برای وصل شدن به شبکه‌ی Tor است. برنامه خودش بهترین روش اتصال را پیدا می‌کند، بریج‌های تازه را جمع می‌کند و در صورت نیاز کل ترافیک گوشی را از Tor عبور می‌دهد. بدون تنظیمات پیچیده؛ فقط یک دکمه.

<br>

| | امکان | توضیح |
|:-:|---|---|
| 🔌 | **اتصال خودکار** | روش‌های webtunnel، snowflake، obfs4 و meek را به‌ترتیب امتحان می‌کند و آخرین روشِ موفق را اول می‌گذارد |
| 🌍 | **VPN سراسری** | ترافیک TCP و DNS کل گوشی از Tor می‌گذرد (با `VpnService` و `hev-socks5-tunnel`). خود برنامه از تونل مستثناست تا حلقه ایجاد نشود |
| 📱 | **انتخاب برنامه‌ها** | می‌توانید فقط برنامه‌های دلخواه را از Tor عبور دهید |
| 🧦 | **پروکسی محلی** | SOCKS5 و HTTP روی `127.0.0.1`، با دکمه‌ی «افزودن به تلگرام» |
| 🌐 | **انتخاب کشور خروجی** | با فایل‌های رسمی GeoIP، بدون نیاز به اینترنت اضافه روی گوشی |
| 🔄 | **بریج‌های همیشه تازه** | هر ساعت روی گیت‌هاب و در صورت نیاز مستقیم داخل خود برنامه جمع می‌شوند |

## 🔗 روش‌های اتصال

| روش | ویژگی | مناسب برای |
|---|---|---|
| ⭐ **خودکار** | همه‌ی روش‌ها را به‌ترتیب امتحان می‌کند | پیشنهاد ما برای همه |
| 🕸️ **webtunnel** | شبیه ترافیک معمولی HTTPS | بهترین گزینه برای ایران |
| ❄️ **snowflake** | از طریق پروکسی‌های داوطلب (WebRTC)، بریج لازم ندارد | وقتی بریج‌ها کار نمی‌کنند |
| 🎲 **obfs4** | ترافیک را شبیه داده‌ی تصادفی نشان می‌دهد | شبکه‌هایی که webtunnel در آن‌ها مسدود است |
| 🌩️ **meek_lite** | از طریق CDN؛ کندتر ولی مقاوم | آخرین راه‌چاره |
| 📄 **vanilla** | بریج ساده بدون مبهم‌سازی | آزمایش و شبکه‌های باز |
| 🚫 **مستقیم** | بدون بریج | در ایران معمولاً مسدود است |

## 🧠 بریج‌ها چطور به‌روز می‌شوند؟

بریج‌ها از دو مسیر تأمین می‌شوند و برنامه خودش میان آن‌ها تصمیم می‌گیرد:

| مرحله | چه اتفاقی می‌افتد | چه زمانی |
|:-:|---|---|
| **۱** | فایل `bridges.json` ریپوی شما (شاخه‌ی `bridges`) از چهار آدرس گرفته می‌شود و **تازه‌ترین** نسخه انتخاب می‌شود | همیشه، اول از همه |
| **۲** | اگر فایل سالم و **کمتر از ۲۴ ساعت** قدیمی بود، همان استفاده می‌شود | فایل سالم و تازه |
| **۳** | اگر فایل **نبود، خراب بود یا بیشتر از ۲۴ ساعت** گذشته بود، برنامه خودش مستقیم از منابع اصلی جمع می‌کند | فایل ناموجود، خراب یا قدیمی |
| **۴** | لیست داخل APK فقط برای روشی استفاده می‌شود که در لیست تازه هیچ بریجی ندارد | آخرین پشتیبان |

| روش | چه زمانی اجرا می‌شود |
|---|---|
| ⚡ **خودکار** | بعد از هر اتصال موفق (از راه Tor). فقط وقتی جمع‌آوری کامل انجام می‌دهد که لیست فعلی بیشتر از ۲۴ ساعت قدیمی باشد |

> اگر برنامه خودش جمع‌آوری کند، تست TCP ممکن نیست و بریج‌ها بر اساس **تعداد منابعی که تأییدشان می‌کنند** رتبه می‌گیرند (پورت‌های ۴۴۳ و ۸۰ اولویت دارند).

## 🛠️ راه‌اندازی (فقط یک بار)

برای ساخت نسخه‌ی خودتان کافی است گیت‌هاب را آماده کنید. بقیه‌ی کارها را اکشن انجام می‌دهد.

1. یک ریپوی **Public** در گیت‌هاب بسازید. ریپو باید عمومی باشد تا برنامه بتواند بریج‌های تازه را دانلود کند.
2. **Settings ← Actions ← General ← Workflow permissions** را روی **Read and write permissions** بگذارید و ذخیره کنید.
3. **Settings ← Secrets and variables ← Actions ← New repository secret** را بزنید:

   | فیلد | مقدار |
   |---|---|
   | Name | `SIGNING_PASSWORD` |
   | Value | یک رمز طولانی و دلخواه |

   > [!WARNING]
   > این رمز را جای امن نگه دارید. بدون آن، نسخه‌های بعدی روی نسخه‌ی قبلی نصب نمی‌شوند.
4. **Add file ← Create new file** را بزنید، اسم فایل را `.github/workflows/uctor.yml` بگذارید، محتوای همین فایل را داخلش کپی کنید و Commit کنید. (گیت‌هاب اجازه نمی‌دهد خودِ اکشن، فایل اکشن را بسازد؛ برای همین این مرحله دستی است.)
5. **Add file ← Upload files** را بزنید، فایل `UC-Tor.zip` را آپلود کنید و Commit کنید.

از این به بعد همه‌چیز خودکار است: اکشن زیپ را باز می‌کند، فایل‌ها را جایگزین می‌کند، کلید امضا را (فقط بار اول) می‌سازد، APKها را می‌سازد و در بخش **Releases** منتشر می‌کند.

> [!TIP]
> برای اینکه بریج‌ها همین حالا جمع‌آوری شوند: **Actions ← UC Tor ← Run workflow ← both**

<br>

## 🔁 نسخه‌های بعدی

فقط زیپ جدید را آپلود کنید. نسخه‌ی جدید با **همان کلید** امضا می‌شود، شماره‌ی نسخه‌اش خودکار بالا می‌رود و روی نسخه‌ی قبلی نصب می‌شود.

| ✅ انجام دهید | ❌ انجام ندهید |
|---|---|
| زیپ جدید را آپلود کنید | شاخه‌ی `signing-keys` را حذف نکنید |
| رمز `SIGNING_PASSWORD` را نگه دارید | اسم فایل اکشن را عوض نکنید |

اگر بخواهید فایل اکشن هم از داخل زیپ به‌روز شود، یک Personal Access Token با دسترسی `Contents` و `Workflows` بسازید و با نام `WORKFLOW_TOKEN` در Secrets بگذارید.

<br>

## 🗺️ انتخاب کشور خروجی و فایل GeoIP

برای اینکه Tor عبارت `ExitNodes {de}` را بفهمد، باید فایل‌های `geoip` و `geoip6` رسمی Tor را داشته باشد. تسک `downloadGeoip` در `app/build.gradle.kts` هنگام بیلد آن‌ها را از مخزن رسمی Tor داخل `app/src/main/assets/geoip` می‌گذارد (چند آدرس جایگزین دارد). برنامه موقع اتصال آن‌ها را به حافظه‌ی داخلی کپی می‌کند و در torrc با `GeoIPFile` و `GeoIPv6File` معرفی می‌کند. اینترنت اضافه روی گوشی لازم نیست.

| حالت | نتیجه |
|---|---|
| دانلود موفق | انتخاب کشور کار می‌کند |
| دانلود ناموفق | بیلد خراب نمی‌شود، در لاگ هشدار `[UC-GEOIP]` می‌آید و فقط انتخاب کشور در آن نسخه کار نمی‌کند (حالت «خودکار» عادی است) |
| فایل‌ها دستی در `app/src/main/assets/geoip/` | دانلود انجام نمی‌شود و همان‌ها استفاده می‌شوند |

<br>

## ✈️ استفاده با تلگرام

بعد از اتصال، دکمه‌ی **«افزودن به تلگرام»** را بزنید. تلگرام پروکسی SOCKS5 روی `127.0.0.1` را اضافه می‌کند.
